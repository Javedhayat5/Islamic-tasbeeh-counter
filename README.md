# Islamic Tasbeeh Counter – Digital Dhikr App

A responsive digital Tasbeeh counter built with HTML, CSS, and vanilla JavaScript.

## Features
- Interactive counter with animated bead ring
- Preset Dhikr selections with Arabic text, transliteration, and meanings
- Add, edit, and delete custom Tasbeeh entries
- Adjustable target counts
- Completion feedback and optional device vibration
- Responsive mobile, tablet, and desktop layout
- Custom entries saved in the browser with localStorage

## Run locally
Open `index.html` in a modern web browser. No build tools, package installation, API key, or backend are required.

## Deploy with GitHub Pages
1. Upload `index.html` and `README.md` to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Wait for deployment. Your site URL will appear in the Pages settings.

## Data note
Custom entries are stored in the current browser's local storage. They do not sync across devices or browsers.

## Built with
HTML5 · CSS3 · Vanilla JavaScript · localStorage API
